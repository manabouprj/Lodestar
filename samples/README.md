# Presentation samples (fictional demo data)

* `lodestar-dashboard.html` - self-contained CISO dashboard for 8 fictional organisations (opens offline in any browser)
* `reports/<organisation>/` - weekly, monthly and quarterly reports in HTML (print to PDF from the browser), Markdown and JSON

Regenerate at any time with `python -m lodestar demo`. All organisations, people, hosts and
`*.example` domains are invented; CVE identifiers are real public CVEs used for illustration.
